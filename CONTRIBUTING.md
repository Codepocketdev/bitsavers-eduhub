# Contributing to Bitsavers-eduhub

## Setup

git clone https://github.com/Codepocketdev/bitsavers-eduhub.git
cd bitsavers-eduhub
npm install
npm run dev

Check .nvmrc for the Node version.

## Before you open a PR

- Run npm run lint
- No emojis in code, comments, or commit messages
- No filler comments, only comment where the why isn't obvious
- Match the existing code style

## Commit messages

Format: type: short description

- fix: correct mint URL validation in settings
- feat: add relay list import from NIP-65
- docs: update setup instructions

## Opening a PR

1. Fork the repo
2. Branch: git checkout -b fix/short-description
3. Push and open a PR against dev
4. Link any related issue

## What we're looking for

- Bug fixes
- Performance improvements
- Accessibility fixes
- New Bitcoin education content
- UI/UX improvements

Unsure if something's worth a PR? Open an issue first.
